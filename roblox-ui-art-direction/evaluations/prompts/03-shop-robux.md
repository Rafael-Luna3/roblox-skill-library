# Cenário 03 — Loja com Robux/moeda e confirmação

## Prompt de teste
> Quero uma loja para meu jogo de fazenda cozy: sementes e decorações com moeda do jogo (Moedas) e pacotes de Moedas e um passe VIP com Robux. Preciso que seja impossível comprar sem querer, inclusive no controle. Faça pela skill roblox-ui-art-direction o pacote completo (fase A).

## Entradas disponíveis
Nenhum arquivo.

## Entregáveis esperados
commerce.catalog-detail ou alternativa justificada, saldo sempre visível, preço+moeda explícitos, confirmação para moeda do jogo e uso do prompt nativo para Robux, foco inicial seguro, estados (saldo insuficiente com quanto falta, possuído, pending, falha, sucesso, prompt cancelado), servidor autoritativo (ProcessReceipt / verificação de passe), manual queue para criar produtos reais.
